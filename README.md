# Jurisync Website

Professional, responsive frontend for **Jurisync** — an online company registration and legal services provider.

## Highlights

- Modern React + Vite + TypeScript setup
- Responsive legal-tech landing page design
- Accessible semantic sections, keyboard-friendly FAQ accordion, and visible focus states
- Lead capture form with client-side validation (name, email, phone, service, message)
- Core sections: hero, trust indicators, services, process, pricing, testimonials, FAQ, and contact
- SEO basics in `index.html` (title, description, Open Graph tags, favicon, theme color)
- Informational legal disclaimer included (no individualized legal advice)

## Stack

- React 19
- TypeScript
- Vite

## Getting Started

```bash
npm install
npm run dev
```

Open: `http://localhost:3000`

## Available Scripts

- `npm run dev` – start development server
- `npm run build` – production build
- `npm run lint` – TypeScript type-check (`tsc --noEmit`)
- `npm run preview` – preview production build locally

## Customization Points

- Update landing content and sections in: `src/App.tsx`
- Update visual styling and responsive behavior in: `src/index.css`
- Update metadata and SEO values in: `index.html`
- Replace icon with brand asset in: `public/favicon.svg`

## Notes

- Pricing shown on the website is illustrative unless you replace it with official pricing.
- Testimonial cards are explicitly marked as sample/demo content until real client approvals are available.
