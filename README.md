# Jurisync

Jurisync is a modern legal-tech platform designed to simplify online company registration and access to essential legal services. The project provides a professional, user-friendly experience for founders, entrepreneurs, startups, and businesses seeking reliable support with business formation, compliance, documentation, and related legal needs.

## Overview

Jurisync brings business registration and legal service discovery into one convenient digital experience. Its goal is to make complex legal and business processes easier to understand, easier to start, and easier to manage online.

### Key Areas

- Online company and business registration
- Private limited company and LLP registration support
- GST and tax registration assistance
- Trademark and intellectual property support
- Business compliance and annual filing guidance
- Contracts and legal documentation
- Startup-focused legal support
- Online enquiry and service request experience

## Features

- Professional and responsive user interface
- Service-focused landing pages
- Clear calls to action for prospective clients
- Interactive FAQ and enquiry experiences
- Responsive layouts for desktop, tablet, and mobile devices
- Modern animations and visual interactions
- Accessible, conversion-oriented design
- Informational legal disclaimer for responsible use

## Getting Started

### Prerequisites

- Node.js 18 or later
- npm, pnpm, or another compatible package manager

### Installation

Clone the repository and install its dependencies:

```bash
git clone https://github.com/JitendraSuryavanshi/jurisync.git
cd jurisync
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

The application will be available at the local URL shown by Vite, typically `http://localhost:3000`.

### Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

### Type Checking

Run the TypeScript check:

```bash
npm run lint
```

## Project Purpose

Jurisync is intended to demonstrate how a digital legal-services platform can present business registration and legal support options in a clear, trustworthy, and accessible way. The website can be extended with authentication, payments, document uploads, customer dashboards, appointment scheduling, notifications, and secure backend integrations.

Website content should not be treated as individualized legal advice, a substitute for professional consultation, or a guarantee of registration, approval, or a particular legal outcome. Users should consult a qualified legal or business professional for advice specific to their circumstances.
